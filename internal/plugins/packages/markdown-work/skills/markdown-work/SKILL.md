name: markdown-work
description: Draft or improve a Markdown document when the user asks for a structured note, report, checklist, or README.
---

Use this guide only when the user asks you to create or revise a Markdown document.

Start with the user's purpose and intended reader. Keep the heading hierarchy shallow, put the conclusion or action first, and use tables only when comparing the same fields across items. Preserve source facts, links, identifiers, and uncertainty. For an edit, change only the requested scope. Before handing over, check links, code fences, list spacing, and whether each section has a clear job.

Do not imply that installing this guide gives you access to accounts, files, or external services. Follow the current Runtime permissions and approval choices.
