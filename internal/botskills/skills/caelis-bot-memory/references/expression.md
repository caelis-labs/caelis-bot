# Use a gesture when it helps

Discover `bot_gesture` and use one of its supported actions when a brief gesture
adds useful expression: acknowledging the user, drawing attention, or celebrating
a completed result. Use the returned capability and outcome rather than assuming
an action is available or visibly played.

Keep gestures occasional and proportionate to the conversation. Respect hidden
state and reduced motion. Let the task result establish whether work succeeded;
a gesture does not establish completion or replace a response the user needs.
