# 产品与边界

Caelis Bot 是面向非技术用户、具有持续身份的常驻个人助手。用户用自然语言交代事情、
提供材料、作出必要决定并取得结果；桌面角色负责存在感、情境表达与唤起。
对外名称固定为 Caelis Bot，“小爱”是默认角色，不是另一个产品或会话身份。

## 常驻入口与交互

- macOS 产品常驻菜单栏，桌宠独立显示、拖动、等比缩放；聊天与设置按需打开，没有主仪表盘。
- 一个长期 Bot，不向用户展示新 Session、工作区树、线程 ID、终端面板或开发者监控导航。
- 关闭面板、隐藏角色、关闭任务观察窗不会取消工作或退出；停止、退出和 Runtime 切换是独立操作。
- 角色、服装与头像切换不改变对话身份、任务或授权。制作源属于私有资产仓库，公开仓库只消费成品。
- 简单日常工作直接处理；代码、研究与制品制作由独立 Worker 承担，Bot 负责委派、核对和汇报。
  用户无需理解内部线程；任务入口提供观察和停止原工作所需的事实。

单击角色切换聊天，菜单栏入口打开或聚焦同一聊天窗口。聊天、设置、气泡和任务观察各自保留
生命周期；草稿、附件和阅读位置不能因打开另一个面板而丢失。阅读气泡不抢键盘焦点，
透明区域把点击交还下层应用。角色隐藏、离屏和系统减少动态效果影响呈现，不改变工作状态。

角色表达使用真实活动事实；轻量 Desktop/Dock/ActiveWindow 上下文驱动本地姿态、注视、待机与
独立道具，不运行空闲模型。前台窗口不等于任务窗口，几何观察不等于内容访问或操作授权。
用户拖动、隐藏、减少动态效果与待决交互优先于装饰行为。动画不证明执行、成功或批准。

## 连接与授权

首次使用选择可用 Runtime、完成必要认证并确认模型，再选择附加功能、填写 Bot 介绍并开始聊天。
介绍是普通用户消息，由 Bot 维护记忆。设置按用户目的组织，渐进展示高级连接和存储选项。
本机选择先保存再应用；“已保存”和“已生效”必须区分，恢复期间保留可用连接、原工作和填写内容。

macOS 安装包内置 Caelis，使用共享 Host、账号与模型配置；Codex 使用用户本机安装，不能静默安装。
Runtime 能力可以比 UI 广，只有完整路径工作后才能宣传为已交付能力。
Windows x64 使用原生外壳；Linux 提供无桌面服务与浏览器入口。平台产物、契约测试和真实 GUI
验收各自独立，支持与发布条件见[开发](development.md)和[发布](release.md)。

系统权限只在实际需要时申请；读取状态不申请权限，拒绝后保留其他功能，不反复弹窗。
F1 截屏选区、标注与 Ask Bot，F3 剪贴板贴图属于可关闭的附加功能；发送只使用用户确认的文档。
图片能力须由当前模型明确支持，截图不授权持续采集桌面。普通聊天图片不受附加功能开关限制。

记忆文件与只读观察遵循原生权限；派生/续接 Worker、修改持续安排由 Runtime 自动审查。
自动审查拒绝、失败或超时不能生成手工 Allow 绕过入口。真正需要用户决定的请求保留原生选项。
Caelis 的 Computer Use 由 Runtime 内置 Desktop World 提供，按连续任务 Turn、App 授权；
系统权限独立生效。当前输入共享系统焦点和鼠标，未知操作只能查原回执，不能重复输入。
Codex 不由 Bot 接入 Desktop World。具体权威边界见[架构](architecture.md)。

## 记忆、跟进与消息

Notebook Markdown 是用户可编辑的长期记忆真源；Bot 用原生文件工具维护 `MEMORY.md` 和详细笔记。
用户修改和删除应保留，不自动从旧历史恢复，不自动提交 Git 或同步云端。
Bot 按上下文需要整理笔记并提交交接，更换内部上下文仍保留同一个产品身份、原任务与未知回执。
空闲、升级或单纯达到时间/回合数不触发模型整理；用户输入优先，交接失败保留原对话。

在已委托目标和授权范围内，需要稍后、条件满足或任务完成后继续的工作，应建立真实安排。
简单安排定时唤醒；脚本、工具或原生事件采集结构化结果，本地条件决定是否唤醒模型。
隐藏角色、锁屏或未知在场状态不是统一禁令；忙碌、授权、取消、期限、去重和预算继续限制派发。
桌面输入工具保持自身权限与锁屏边界。电脑睡眠或应用退出不能承诺按时执行，注册成功不等于手机送达。

桌面、Telegram 和开发版微信文本渠道共用一个 Bot 对话；各渠道独立保存接收与投递回执。
Telegram 面向一个已配对私聊；微信限定已配对用户的私聊文本，并受接收窗口和本地发送预算限制。
审批和问题保留可复制的编号命令，按钮只是额外呈现，决定始终由原请求与 Runtime 核准。
节选、已发送尝试和未知投递不能冒充全文送达；一个渠道的预算或故障不减少其他入口的输出。
宿主任务完成、自动审查与维护输入留在内部，Bot 给用户的实际结论、文件和必要请求正常呈现。

系统通知用于有实际内容的主动提醒、必要决定和可执行的更新提示；普通回复、完成状态和技术异常
不另发通知。提醒显示本次内容，通知点击只打开应用，不直接授权、重试或执行。

## 远端执行与可用性

本机 APP 保持长期 Bot 身份；远端环境是另一台运行中的 Bot。连接需要可达地址与对方明确批准，
A→B 和 B→A 分别授权。SSH 只提供网络通道，不安装 helper 或管理远端模型；网络可达不等于授权。
没有指定机器时默认本机；续接保留原机器、Runtime 与执行 owner。远端账号、模型和 Worker 配置
由远端管理，不复制凭据、不自动再次转派、不迁移 Bot、不提供通用文件同步。
远端任务在发起方观察和处理问题/审批；执行方不把外来工作放入自己的聊天、普通任务列表或通知。
删除连接是本地操作，保留历史任务与原绑定；不能把同名新机器当作原执行环境。

局部故障只影响所属能力。聊天、控制入口和未受影响功能持续响应；在期限与重试预算内静默恢复，
必要时原位显示普通进度。技术错误、原始异常和内部重试不进入聊天、气泡、通知或设置警告。
只有真正需要输入、授权或选择时才请求用户操作。恢复耗尽且不能安全继续时，提供单一恢复界面，
允许复制隐私安全的诊断信息并重启；保留原工作，不能自动循环重启。

聊天使用本地 IM 记录，Runtime 独立保存执行与工具历史。重连只同步最近消息，不以全部 Worker
历史为连接前提。所有恢复保留原任务、审批目标和未知回执，不重做结果不确定的操作。
