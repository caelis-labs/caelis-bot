# 产品与方向

Caelis Bot 是面向非技术用户、具有持续身份的常驻个人桌面助手。用户通过自然语言交代事情、
提供材料、作出必要决定并取得结果；桌面角色负责存在感、情境表达与唤起。对外名称固定为
Caelis Bot，“小爱”仅是默认角色，不是另一个产品或会话身份。

## 产品边界

- macOS 菜单栏常驻，桌宠独立显示、拖动、等比缩放。聊天与设置按需打开；没有主仪表盘。
- 一个长期 Bot；不暴露新 Session、工作区树、线程 ID、终端面板或开发者监控导航。
- 关闭面板、隐藏桌宠不会取消工作或退出。明确停止、退出和 Runtime 切换拥有独立生命周期。
- 简单日常工作直接处理；代码、研究与制品制作由独立工作任务承担，Bot 负责委派、核对和汇报。
  不要求用户先说“创建线程”。角色、服装和头像切换不改变身份、任务或授权。
- 后端能力可以比 UI 广；只有完整路径工作后才宣传为已交付能力。Core 提供通用可装配能力，
  Bot 决定自己的 Runtime 配置；不让 Core 为 Bot 裁剪环境。

## 交互

单击角色打开输入，双击打开对话；输入接受后收起，拒绝或未知时保留草稿。菜单栏负责设置、
显示/隐藏与退出。透明区域把点击交还下层应用，阅读气泡不抢键盘焦点。角色缩放范围 65%–160%。
桌宠跟随同一显示器的 Space，切换不改变用户保存位置，也不唤回主动隐藏的角色。

头顶气泡显示最新助手正文、必要状态和一行工具进度；安全 Markdown 与聊天一致。
悬停展开、移开收起，正文可滚动；展开按钮位于顶部一行，正文/表格使用全宽。
原生 Glass 配合较高不透明度的阅读底层；旧系统保留可读的退化材质。高度受显示器可用空间约束。
当前回复按字素平滑呈现，历史与减少动态效果直接显示；执行、审批和停止状态立即更新。

任务入口是透明底三个点，运行时轻微律动，空闲/隐藏/减少动态效果时静止。卡片展示原生任务
事实；悬停冻结排序而不冻结状态。完成项默认保留 30 分钟，锁定项常驻。pin/unpin/clear 只管理
呈现，不取消任务。关闭卡片关联终端时等待实际退出；取消关闭保留卡片，Worker 继续运行。
点击卡片在用户偏好的外部终端观察同一工作；复用专属实例，不向旧 shell 注入命令。

F1 打开屏幕选区、标注与脱敏；F3 从剪贴板贴图。选区可使用当前窗口或屏幕区域，工具按钮
随系统深浅色变化。Ask Bot 使用当前模型的图片能力，只在明确支持时可用；复制、标注、贴图
独立于模型。发送只使用用户确认的文档，不暗中连续采集桌面。

首次使用先介绍 Bot 名字和可选描述，再单独选择附加功能，随后提供可跳过的系统权限引导与 Runtime 连接。
附加功能是可随时更改的产品选择，不是 macOS 授权；默认开启 F1 截屏与 F3 贴图，关闭不影响普通聊天图片。
返回权限步骤前可回到附加功能修改选择；只有成功保存选择后才继续。已完成旧引导的安装不重新展示新步骤。
介绍是普通用户消息，身份由 Bot 写入记忆；设置不重复提供名字/人格表单。
设置按行为组织、渐进展示高级连接/存储选项，不把模型与协议细节铺成默认导航。
系统权限由 macOS 管理，读取状态不触发申请；普通申请不重置已有授权。

## 连续性与主动工作

Notebook Markdown 是可编辑的长期记忆真源；Memory 提供线索检索与更正/遗忘。普通操作属于
产品允许的低风险工作区，不反复审批。删除的内容不自动从历史恢复。
空闲 Dream 整理用于持续上下文；结合上下文用量、有效增量、近期模型活动和连续清醒空闲择机执行，
休眠唤醒或缓存机会已过时不补跑。整理时桌宠轻轻打瞌睡并显示 zzz，聊天显示临时状态；
用户随时可以继续说，审批与恢复提示优先。普通整理在下次用户输入交接，App 版本升级在恢复空闲后
主动交接新配置。同版本重启恢复原绑定。用户输入优先，未知结果按原请求恢复，不能换 ID 重试。

提醒在应用运行时调度，关怀使用本地事件条件，不运行空闲 LLM 轮询。隐藏角色不停止调度；
退出、锁屏、忙碌、过期与打扰预算限制派发。关怀按实际可展示的结果计量，静默完成不消耗额度。

审批目标是尽量减少手动交互：记忆、只读观察和本地呈现直通；派生/续接独立 Worker、修改持续
安排交给原生 Guardian。Computer Use 每个连续任务 Turn、每个 App 授权一次，任务内不逐次
点击审查。新的 App/Turn 重新授权；系统权限、登录、必要信息选择仍由用户完成。
Computer Use 统一采用自研 Desktop World，优先使用对象语义操作，以完成任务为先、尽量减少
对用户输入的干扰。当前 alpha 仍共享系统焦点与鼠标，不承诺独立后台输入设备；同一授权任务内
不为必要的前台切换反复询问。观察按范围与增量返回，截图按需，未知结果只能查原收据，不能重复输入。
审查拒绝/失败/超时是事实，不生成手工 Allow 绕过入口。详细策略见[运行时](caelis-integration.md)。

## 发展顺序与未交付范围

近期先完成 macOS 基础 Computer Use 和日常工作闭环，再独立验证角色行动与桌面操作联动。
早期以开发者持续自用与有辨识度的真实演示为目标，不要求先证明普通用户长期留存。
3D 模型加聊天/状态 clips 是接入基础，不能代替情境表达的产品价值。

已建立轻量 Desktop/Dock/ActiveWindow 快照、本地姿态/注视、六组待机和独立纸飞机。
未来把可信桌面上下文、本地意图调度、原生位置执行与角色姿态分开；用户拖动、隐藏、减少
动态效果及审批优先。前台窗口不等于任务窗口，几何观察不等于内容访问，更不等于操作授权。

通用行动/回执、角色行走与任务窗口关联、虚拟手柄、完整创作者生态仍是探索。实验位于 `poc/`，
不代表生产合同。先用第二种明显不同的身体验证抽象，再决定公共 Character SDK；复杂语义地图、
市场和留存研究后置。制作源属于私有资产仓库，公开仓库只消费成品。

macOS 是当前完整发行目标；Windows 保留接口，原生驱动/安装包另行实施，Linux 桌面端不在计划内。
最低系统、多显示器与真实模型效果的验证边界见[开发与验证](development.md)。

## 远端机器

本机 APP 保持一个长期 Bot 身份。用户在“远程机器”添加 SSH 机器连接，为每台机器
单独完成 Codex 或 Caelis 登录与默认工作模型设置，然后在原有对话中明确指定这台机器工作。
Linux 远端运行完整原生 Runtime 与应用自己的无界面辅助程序。配置与账号凭据不跨机器复制。
没有指定机器时默认本机；续接使用原任务所属机器。没有自动调度、Bot 迁移或文件同步。

Codex 的本机设置只有 Bot 对话模型和默认工作模型。远端只设置该机器的工作模型，不再
激活一个常驻 Bot。Caelis 的 Team 属于默认折叠的可选高级配置；缺少自定义 Team 或读取
高级配置失败都不阻断基础工作。暂未覆盖的 OAuth、ACP 流程清楚引导用户前往远端 TUI。

设置按用户目的区分：“AI 模型”配置本机 Bot 对话与工作模型；“AI 账号”
管理 Bot 驱动 Runtime、模型服务、外部 Agent 和可选 Team；“消息渠道”展示真实可用渠道及其状态；
“远程机器”独立管理 SSH 机器及其工作设置；“附加功能”管理手动截屏与贴图。
模型页保留前往 AI 账号的入口，缺少账号时可直接继续添加连接。
消息渠道总览目前只有 Telegram：一行展示名称、简短用途与实时连接状态，点击进入设置详情，详情可返回总览。
渠道入口可继续容纳未来适配器，但不预展示未实现渠道，也不暗示 Telegram 支持多个 Bot 账号。
返回总览与再次进入保留未提交的临时 token 草稿；离开设置窗口即清除，密码不持久化到渲染层。
旧 Telegram 深链直达详情，旧聊天连接入口和 Runtime/账号入口继续可用。

宿主任务完成事件只作为内部唤醒输入，原文不显示于聊天或镜像到消息渠道。Bot 根据任务原始收据
读取结果，给用户的实际结论、文件和后续请求仍正常显示。来源由原生持久化绑定确认，不能根据
消息文字或 ID 形状推断；用户恰好输入相同文字也必须原样呈现。

宽设置窗口使用右侧编辑区，空间不足时使用共用草稿的居中弹窗。连接按钮固定在底部，
错误与主机指纹可见，关闭编辑器不会停止任务。已有任务保留原 SSH 连接及自己的 Runtime 绑定。
本机与远端均可切换新任务默认工作工具；旧任务的状态不阻止切换，其查看、续跑、停止和观察
继续使用原 Runtime。Bot 仍使用一个委派入口，不逐任务选择后端。Bot 驱动连接的交接与
Worker 默认值相互独立，本机默认工作工具放在“AI 模型”中，Caelis Team 仍保持可选。
脚底 Dock 沿用现有操作，远端卡片只补充机器名；打开用户偏好的外部终端，通过 SSH
连接原任务的原生 TUI。关闭观察连接不停止 Worker，无法确认原绑定时不创建替代任务。
范围与当前验收边界见[远端机器首版](remote-machines-v1-plan.md)。
