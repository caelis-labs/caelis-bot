## 已实现的产品路径

- 自动发现并检查锁定 Codex binary；读取账户状态，已有账户可直接开始。
  无账户时提供原生 ChatGPT browser login/cancel。未提供私有凭据输入或外部 token 刷新。
- 一个长期 Bot 身份；接受发送后收起空闲输入，气泡显示最新助手输出与必要状态。
  审批在原气泡中展开；可选聊天窗口支持发送/补充、停止、审批和文件结果，默认不显示工具流水。
  三种表面跟随系统明暗；没有新会话或工作区导航。拒绝/未知发送保留草稿，不误收起当作成功。
  隐藏/关闭面板不取消任务。结果文件按钮仅在 Finder 显示，不执行文件或命令。
- 最多 8 个普通文件、单个 20 MiB。原生选择/拖入后显示临时元数据，发送时重新读取、
  校验并复制到本机 `.attachments`。PNG/JPEG/GIF/WebP 头映射 native localImage；
  其他文件以明确的本地副本路径供工具读取，不称为通用远程上传。
- + 中展示 skills/list 返回的已启用技能，包括插件提供的技能。引用使用 native skill 输入。
  没有借用 Codex Desktop 工具列表冒充 Bot 连接。插件整体引用/安装、连接器管理未实现。
- 命令/文件修改/额外权限审批、工具提问、简单 MCP 表单与 URL 请求有对应投影。
  命令精确保留 availableDecisions，包括后端提供的规则选项；权限仅授予请求的子集、
  turn scope。点击角色与模型 prose 均不构成授权。
- 原生请求 ID 配合连接世代和请求代次防止旧按钮批准新请求。提交后等待原生 resolved /
  turn terminal；失败或断线不自动重复授权。未实现方法显式返回 -32601。

## 生命周期与恢复语义

`~/Library/Application Support/Caelis Bot/` 下的 `conversation.json` 仅保存版本、
内部 root/worker thread ID、待确认发送的 client ID；原生对话正文由 Codex 保存。绑定原子写入，
文件 0600；`Work` 为本机执行与结果目录。字符资产、位置偏好和对话身份相互独立。

发送前保存 pending ID；已尝试发送但未收到可靠回执即为 unknown，保留草稿且禁止误重发。
恢复时通过原生 userMessage.clientId 核对；还活着的 owner 只读 thread/read，不重启任务。
断线后新进程 thread/resume 重建历史，不能宣称它自动续跑了被中断的任务。
Bot 不提供新会话；既有绑定接入新工具时通过 resume 配置，不丢弃历史。
`bot.json` 保存独立产品身份/提醒；`preview.json` 保存当前结果确认；草稿由宿主共享并以版本校验。
`draft.json` 保存文本/引用，`draft-files.json` 保存所选本地文件路径；均原子写入 0600，正常重启恢复，不自动发送。

真实复测曾发现：native interrupted 到达后，刚启动的前台 sleep 尚未出现在后台终端
注册表，关闭 App Server 会让它变为孤儿进程。旧的短 sleep/仅检查 Close 后退出不能充分证明清理。
现已收紧验收为 sleep 60，后台样本在 Close 前必须仍存活，中断样本在额外 Close 前必须已退出。

明确停止/退出/SIGTERM：先从 OS 实际父子关系捕获自有 App Server 后代，保存 PID 与 birth time；
取消 RPC 等待 → 对准确 run 中断 → 有界等待原生终态 → 对 root/已观察到的子线程执行原生
backgroundTerminals list/terminate/clean → 关闭并回收自有 server 及仍匹配已捕获身份的工具。
显式停止再恢复同一绑定，不重发任务。单测覆盖 setsid 后代、无关进程不受影响及失配 birth time。
协议或 OS 捕获/清理失败会报告；不会把 native interrupted 单独当作 OS 进程已消失的证明。
开发 Run 只向本工作区应用发送 SIGTERM，最多等 30 秒，超时拒绝启动第二个 owner。
不会按工具名字批量杀进程，也不会把开发重启称为 detach。

## 剩余限制 / 发行门槛

- P2 核心工作流已通，不代表 Codex 全功能覆盖。尚未实测干净账户登录/取消、外部 MCP
  复杂授权与工具提问、图片模型输入、全部拒绝/断网交叉场景、睡眠/恢复及长任务压力。
- MCP 当前支持简单标量/字符串枚举表单；数组、复杂 schema/约束明确不提供接受按钮。
  URL 必须 http(s)，不能把打开网页当作已授权。插件安装/连接器管理、外部 token 生命周期、
  实时语音、多任务导航不属于本次已实现能力。
- 中断、原生后台注册表和 OS 后代清理均已有真实证据。捕获之前已逃离父子树的后代、
  异常崩溃、远程工作仍不保证清理；PID/birth time 查询与发信号之间不是内核原子句柄。
- 64 条传输事件队列、8 MiB 单行；超限显式断线。没有独立持久事件队列。
  Stderr 丢弃以免泄露内容；已实现状态诊断导出和原生历史分页，未收集完整日志。聊天已支持助手 Markdown、链接及复制，气泡仍为简短摘要。
- 消息气泡位置与非激活状态已验；新气泡在边缘、拖动、Space 切换组合下仍需扩展实机回归，
  不把此前角色单窗拖动验收自动推广为所有新表面场景。
- 宿主共享草稿/附件选择已跨正常退出保存；异常中止在服务接受与本地清空之间可能留下已发送文本，
  不自动重发。已实现 30 天旧附件副本手动移到废纸篓，清理后可能需要重新附加文件。
  结果工作目录目前固定，未实现“另存为”目标选择。
- 依赖用户本机兼容 Codex 与账户，不锁定用户发行版本。早期分发用 ad-hoc ZIP，README 提供
  安装、单应用信任例外和手动更新。Developer ID/公证按用户决定后置，不是此轮 pre-release 门槛。
  P1 外接屏/混合 DPI/拔屏、睡眠、真实 IME 候选和长期功耗验收仍保留。
- macOS 是唯一实现。Windows 只有接口与编译守卫，macOS 完整发行后再实施；Linux 不在计划。
