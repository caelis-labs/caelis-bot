## P2 adapter 边界

保留 task/run/item/request 的原生身份，但不在默认 UI 暴露。附件选择 ID 只是宿主临时
引用，不等于后台 input item。发送前由原生读取与重新验证，adapter 投影实际支持的输入
类型；取消选择不删除原文件，关闭输入框不能取消后台工作。

插件需分别处理可见、已安装、启用、可调用、待授权及失败。不得从生成文本推断授权，
不得给不可调用插件放置“已连接”的标记。[App Server API 概览](https://learn.chatgpt.com/docs/app-server#api-overview)
当前仍把 plugin/list/read/install/uninstall 标为开发中并要求生产客户端暂不调用；
app/installed、app/list 与 MCP 状态是独立接口，不能合并成一个模糊的 enabled 布尔值。
P2 要针对锁定的 Codex 0.153.4 重新生成/检查 schema 和兼容边界，再决定分阶段接入范围。

最新职责：空闲输入只发 prompt；审批在气泡原位展开；运行可停止、完成可 ✓ 收起当前结果。
颜色统一跟随系统。一个长期 Bot，无新会话行为；按用户 prompt 或应用常驻定时激活，
内部 worker 不增加用户导航。详见 [bot-design.md](bot-design.md)。

2026-09-21 菜单收敛：角色右键仅有“对话”“隐藏”；状态栏另有“显示”、设置、检查更新、退出。
低频功能进入统一设置窗口。空闲单击角色仍切换输入框，双击直接打开聊天；单击等待系统
双击间隔以避免输入闪现，拖动不等待。工作中单击打开聊天、待审批时单击展开审批的行为保持。
