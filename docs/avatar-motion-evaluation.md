# 聊天头像动效

2026-09-22：已完成本地 SVG 实现，尚未发布。用户选择参考图中的简化 Bot 风格，
保留粉发、纸飞机与星饰，采用纯色椭圆眼睛、淡腮红，不使用人物精细五官或 3D。

## 取舍

参考用户的 Chat《调研Grok头像实现》及
[Grok Bot 官方设计说明](https://x.ai/news/designing-grok-bot)。采用头像表达工作状态、
详情按需展示的思路；不依赖逆向研究中未独立审计的几何数量、内部状态表或弹簧参数。

分层 SVG 能独立控制视线、眨眼与头部，成品约 2 KiB，无额外库或 WebGL。
不采用整张 PNG 固定周期摇摆，也不加载桌宠整模。

## 当前行为

- 等待、自动审查和流式输出时，仅当前活动消息头像运动；历史头像静止。
- 整个头像轮换弹起回落、抬头探看、小幅点头、侧身倾听、左右观察五组动作，
  不连续重复同组；每组后停顿 0.9–2.1 秒。位移上限约 3.5 pt，倾斜不超过 8°，
  配合不超过 6% 的伸缩。第一秒内即可看到整体移动。
- 视线独立调度，并配合动作看向目标；眨眼独立间隔 2.6–4.6 秒，闭合再睁开约 220 ms。
- 姿态最多更新 30 次/秒。DOM 属性未变化时不重复写入，不触发逐帧 React 渲染。
- 窗口隐藏、头像移出可视区、减少动态效果时取消动画帧并复位；重新可见后从静止开始，
  不追赶隐藏期间的时间。结束工作或停止时卸载动态头像；待审批、断线保留静态头像，详情和操作放在右侧气泡内。
- 保留加载圆点与自动审查、停止、审批、断线等明确反馈；运动不代表真实思考进度，
  不承担授权判断，也不调用模型。
