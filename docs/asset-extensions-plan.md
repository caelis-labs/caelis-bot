# 预置内容与第三方内容包

状态：2026-09-23，本地内容包 v1 已实现，尚未发布。早期发行范围固定为：
**随应用提供预置内容，允许用户导入第三方内容包。**
实际支持范围与创作者操作见 [制作与发布内容包](content-packs.md)。

## 产品与内容分离

应用代码保持免费开源，内容按各自许可证分发。内容包是可以安装、切换的数据资源，
不能携带 JavaScript、原生代码、安装脚本、任意 shader 或工具权限。
更换外观不创建新 Bot，不切换 Caelis/Codex，也不重置对话、任务、权限和模型配置。

```text
Bot：身份 / Runtime / 对话 / 任务 / 权限
                  |
          独立的外观选择
                  |
       内容目录、校验与资源解析
           /             \
     应用预置资源       本地第三方包
```

- **应用层**拥有产品行为和权限。App 与状态栏品牌图标随应用发行。
- **外观层**保存完整角色变体和聊天头像的选择。头像可以跟随角色，也能独立选择。
- **内容层**拥有校验、安装、版本、缓存、资源访问、移除与回退。
- **制作侧**输出公开格式。官方源工程留在私有资产仓库；社区不需要这些源工程或私有工具。

这些边界不要求额外建立仓库、后台进程或发布一个空 SDK。

## 当前实现

| 模块 | 职责 |
| --- | --- |
| `resources/character-pack.json`、`frontend/src/character/assets.ts` | 固定应用预置成品及回退资源 |
| `internal/contentpack` | 共享格式、原生验证、不可变归档、选择状态、受限资源服务 |
| `cmd/content-pack` | 初始化、确定性打包、校验、解包二创，复用同一验证器 |
| `internal/desktop/content.go` | 原生文件选择及导入、移除、切换入口 |
| `frontend/src/appearance.ts` | 向各窗口提供带修订号的外观快照 |
| `frontend/src/AppearanceSettings.tsx` | 设置中的导入、版本选择、角色与头像选择 |
| `frontend/src/character/pet.ts`、`BotAvatar.tsx` | 渲染成品、热切换与加载失败回退 |

内置成品合同仍服务官方构建交接；它不是第三方合同。第三方包采用
`caelis-content` v1，当前只开放 `basic-3d-v1` 与 `png-v1`。
内置增强表情、手指、视角修正和持物逻辑不要求社区角色复制。

## 内容与版本

`.caelispack` 是包含清单、授权文本和列明成品的受限 ZIP。
角色使用自包含 GLB，头像使用静态 PNG；一套服装变体是一个完整 GLB。
包可以包含多个角色/变体/头像，也可以只包含头像。

ID 是稳定引用，版本是不可变发行：同一 ID 和版本不能覆盖不同字节。
新版本与旧版本并存，由用户主动切换，旧版本可用于回退。
未知格式或能力明确拒绝；缺少基础动作可以静止或使用 idle。
作者、许可证均保留，但本地自报来源不构成身份验证。

原生安装器检查路径、文件类型、重复项、软链接、哈希、资源预算和 GLB 外部引用。
模型加载器不是导入边界。资源存在应用数据目录，不写入已签名的 `.app`。
导入经过完整验证、暂存和原子登记，失败不会覆盖旧包。渲染器只读取校验后的本地资源。
切换预载新模型、丢弃迟到结果、释放旧 GPU 资源并更新点击区域；加载失败恢复内置形象。

## 社区制作流程

公开工具和 [开发指南](content-packs.md) 提供从示例到发行的完整步骤：
制作 → 导出 GLB/PNG → 编辑清单 → 打包/校验 → App 实机预览 → 分发 `.caelispack`。
用户导入成品时不需要 Go、Node、Blender、Runtime 登录或制作工程。
允许二创的包可用 `unpack` 还原目录；二创使用新 ID，并保留原始授权和署名。
应用开源不意味着内置人物或所有第三方内容均允许再分发。

仓库中的基础几何是校验夹具，不作为默认人物或发行的角色选项。官方默认形象保持不变。

## 新能力的扩展规则

新增表现能力必须先定义有版本的合同与正反例，再补齐原生校验、渲染、回退、制作说明
和实机验收，最后才开放给创作者。不能通过未经定义的 metadata 暗中开启专属骨架逻辑。

如果后续决定支持挂点配件、桌面装饰或独立蒙皮衣服，需要分别定义挂点/体型、宿主行为、
绑定/遮挡合同；当前格式不声称具备这些能力，也不接受相应字段。

共享核心不依赖 AppKit。未来 Windows 可以复用格式、校验与选择状态，但文件对话框、
路径/ACL、资源服务、GPU 与窗口行为需要原生适配与验收；交叉编译不代表已支持 Windows。
