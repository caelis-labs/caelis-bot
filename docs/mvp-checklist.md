# macOS 首个 MVP 收敛清单

范围：普通用户可独立安装、连接本机 Codex，并通过同一个 Bot 持续聊天和接收提醒。
人物制作由独立会话负责，小爱 v0.4.1 现已接入本地预览。优先功能可用，稳定协议尊重固定 schema；不确定的原生行为才专项实测，
不为首版穷举极端组合。Windows 等 macOS 完整发行后再做，Linux 不列入计划。
早期 pre-release 按用户决定暂不要求 Developer ID 与公证；提供 ad-hoc ZIP、校验值和
单应用信任说明。正式 macOS 完整发行的签名/公证门槛保留。

2026-09-20 路线修订：本表是可用性/预发布门槛（路线 A），不代表产品差异化已经成立。
轻量桌面骨架、六套待机、鼠标/工作互动与独立纸飞机属于近期主线（路线 B / P4.2），首个运行切面已接入，整体仍待自用/观感验收；
随后扩展角色位移与任务空间关联（路线 C / P4.3）。详见[产品发展路线](roadmap.md)和
[交互基线](desktop-behavior.md)。开发者自用与演示是初期目标，用户长期留存不作为前置验证。完整空间能力不阻塞
工程预览，但不能把现有五段 clips 宣传为已完成的桌面理解或 3D 表现力。

| 工作块 | 当前进度 | MVP 剩余门槛 |
| --- | --- | --- |
| 首次连接 | 标准 socket 握手优先，失败回退自动 CLI；无 CLI 版本白名单，按协议检查；独立配置可检测保存手动路径；浏览器登录后自动恢复；README 安装说明 | 干净账户实际登录/取消；回归基线 0.153.4；运行中的 App 须开放标准入口 |
| 审批与恢复 | auto_review 默认；自有 MCP 逐项自动批准；拒绝/超时及原因独立展示；登录失效恢复；未知发送不重放 | 发布前确认实际自动审查拒绝/回退 UI；常见断网/进程退出的最终回归 |
| 长期聊天 | 同一 Bot、内部工作 Thread、重启恢复；草稿/附件选择持久化；最近 20 轮启动、向前分页；30 天旧附件副本可移入废纸篓 | 旧协议回退仍完整恢复；超大单轮/长期内存压力后续优化 |
| 提醒送达 | 持久调度、应用常驻、忙时排队、睡眠错过合并；原生系统通知和独立权限入口；原生授权已验 | 横幅展示/点击返回的最终确认；真实睡眠/唤醒与时区的最小验收 |
| 消息与文件 | 三表面系统主题、IM 聊天、最新回复气泡、文件选择与结果定位；助手 Markdown、双侧气泡、悬停复制；真实图片输入已验 | 结果另存为 |
| 外部工具 | 原生渐进发现、技能引用、简单 MCP 表单/URL 授权 | 一个真实外部工具的发现→授权→调用→失效恢复闭环；不做完整市场 |
| 角色接入 | 小爱五段动作、渲染参数、动态 mask、隐藏暂停、静态回退；原生已显示；用户反馈动作表现不足 | 动态角色物理鼠标确认、长期功耗与角色公开分发授权；表现力另按 P4.2 验收 |
| macOS 日常稳定性 | 单屏 Retina、原生拖动、穿透、Space 跟随已有火柴人证据 | 外接屏/拔屏、真实 IME、空闲 CPU/GPU/内存与常用窗口组合 |
| 发行与诊断 | ad-hoc ZIP/SHA-256；README 安装/信任放行/手动更新/数据保留；菜单手动检查公开版本；白名单诊断 JSON 本机导出；不携带 Codex | 干净机器安装验收；Developer ID/公证后置 |

通知不意味着退出后仍执行。首版明确退出后暂停，睡眠期间的提醒在醒来后合并。
未授权通知或开启专注模式时不能保证横幅展示。系统通知正文只显示提醒标签或通用结果提示，
不复制对话、审批命令或凭据。点击后进入聊天，确认/拒绝仍走原生请求。

本轮三项重点已闭环：分页协议/45 轮回归、原生历史恢复；合成旧附件原生移入废纸篓；
系统保存面板导出 0600 诊断报告。见 维护验收摘要（历史记录私有归档）。
分页加载保留已读取的消息，不是无限历史虚拟化；附件清理需要用户主动确认，且工作/未知发送/
后台终端运行时不清理。报告只有当前状态及数量，不收集完整原生日志。

暂不推进：Caelis adapter、独立 Memory、语音、Appshot/CU 画中画、角色市场、复杂动画库（不含近期基础 3D 表现）、
完整插件管理和跨平台发行。检查点提交仍需要新的用户授权。

菜单现已收敛为聊天、隐藏/显示、设置、检查更新与退出；低频配置共用一个设置窗口。
双击角色可从空闲态直接进入聊天，单击仍打开输入胶囊。新版本提示仅元数据读取，实际安装保持手动。
