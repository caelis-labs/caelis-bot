# 角色身边的任务气泡

2026-09-24 · **交互 POC，未接入正式 Bot 或真实任务。**

根据用户最新反馈，移除初版的分类图标、状态卡、任务标题、详情列表、结果页和审批入口。
只保留三件事：脚边收起的小入口，展开后外观相同的任务气泡，悬停时显示两行原始 prompt。
数字仅表示顺序，不需要 Bot 推断分类或选择图标。点击气泡打开该任务对应的外部终端。

## 当前示意

- 悬停小入口 180ms 展开；移开 400ms 收起。点击或键盘聚焦也能展开。
- 悬停/聚焦气泡，显示原始任务输入，CSS 折叠到两行；不生成摘要或新标题。
- 点击仅显示模拟的终端打开反馈，**不会启动终端或操作任务**。
- 左右键选择，Tab 遍历，Escape 收起。没有额外菜单、任务详情页或审批动作。
- 角色复用仓库已有 GLB、加载、光照与 CharacterAnimation：展开 attention，点击 nod。
  本地动作受冷却、页面可见性和减少动态效果约束，没有模型调用或状态轮询。
- 背景、页眉和底部说明只属于预览页面，不是正式 Bot 的新主窗口。

运行：本目录 `npm ci && npm run dev -- --port 4175 --strictPort`。
只监听 127.0.0.1。`npm run build` 只生成本地构建，不发布。
源码引用本仓库现有角色资源；来源和授权见
`../../frontend/public/models/caelis-SOURCES.md`。本目录依赖独立，未改变正式应用依赖。

## 最小生产接入

复用现有 `internal/tasks/manager.go` 任务账本与运行时绑定。前端只需受管任务句柄、
原始 prompt 和稳定顺序，宿主提供 `OpenTask(handle)`。不新建分类体系、图标生成器、
任务数据库或嵌入终端。打开气泡不能创建另一条 Worker，也不能重复发送原始 prompt。

原始 prompt 应使用该 Worker 首次创建时保存的输入，不能拿后来的模型总结替代。
多任务保持稳定排列，悬停期间不挪动鼠标下的目标；超过短行容量时可在同一行滚动。
任务的保留/归档沿用产品账本生命周期，本 POC 不新增自动清除规则。

Bot 和 TUI 连接同一受保护的 App Server，通过原生协议收发与观察。Bot 继续使用
事件通知获取进度、结果和审批；气泡只负责访问。收起气泡、关终端、隐藏角色不能取消
Worker。运行时未就绪时核对既有绑定，不静默新建任务。

`OpenTask` 在宿主检查归属、解析当前 endpoint 和原生任务标识，再安全构造 attach
命令；renderer 和原始 prompt 都不是 shell 来源。第一版可以可靠打开默认终端；
跨终端的已开窗口复用需要各自支持，不能只靠进程存在声称聚焦成功。

后续正式接入已将 Codex `watchChild` 改为订阅事件，并跟踪用户在同一 Worker 发起的新回合，
重连时恢复订阅。原生任务气泡与外部终端入口也已落地；实现与验证边界见
[任务委派](../../docs/task-delegation.md)。协议 POC 保留在 `../eventbot/`；本目录仍是独立的
界面示意，不连接真实任务。Caelis 后续对齐共享访问。

原生气泡作为随角色移动的轻量非激活表面，命中区只覆盖可见按钮；提示气泡不抢焦点，
靠屏幕边缘由宿主限制位置。拖动、输入和审批优先于装饰动作。
浏览器验收不替代原生命中、多屏/Space、焦点、真实终端、恢复或 VoiceOver 验收。
